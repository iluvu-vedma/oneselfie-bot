# Инструкция: Использование кастомных (премиум) эмодзи в сообщениях и цветных кнопок для Claude Code (Библиотека grammY)

Благодаря крупному обновлению Telegram (начала 2026 года), боты теперь могут использовать **кастомные анимированные и статические эмодзи** в сообщениях и кнопках. Больше **не требуется покупать дорогой NFT-юзернейм на платформе Fragment** или иметь подписку Telegram Premium у самого бота. Анимация эмодзи воспроизводится у всех пользователей, даже если у них нет Premium-подписки.

Эта инструкция адаптирована для разработки на языке TypeScript / JavaScript с использованием современного фреймворка **grammY**. Она подготовлена для того, чтобы ИИ-ассистент (например, Claude Code) мог сразу использовать эти шаблоны в проекте.

---

## 1. Общие правила и требования

Для корректной отправки кастомного эмодзи необходимо знать его уникальный `custom_emoji_id` (Telegram ID) и соблюдать синтаксис разметки.

### Ключевые условия:
1. **Режим разметки (Parse Mode):** Сообщение должно отправляться с включенным форматированием `HTML` или `MarkdownV2`. В grammY это указывается в параметрах вызова метода.
2. **Запасной вариант (Fallback Emoji):** Внутри тега разметки обязательно должен находиться **ровно один стандартный Unicode-эмодзи** (например, `😊`). 
   * *Почему это важно:* Если у пользователя устаревший клиент или эмодзи будет удален, Telegram автоматически отобразит этот стандартный эмодзи. Если внутри тега не будет ровно одного стандартного эмодзи, сервер Telegram проигнорирует разметку и отобразит её как обычный текст.

## 2. Разметка для сообщений в grammY

### Вариант А: HTML (Рекомендуемый)
Синтаксис тега:
```html
<tg-emoji emoji-id="ID_КАСТОМНОГО_ЭМОДЗИ">👉</tg-emoji>
```

**Пример отправки сообщения в grammY (Node.js / Deno):**
```typescript
await ctx.reply("Привет! Вот анимированный эмодзи: <tg-emoji emoji-id='5368324170671202286'>🔥</tg-emoji>", {
    parse_mode: "HTML"
});
```

### Вариант Б: MarkdownV2
Синтаксис ссылки:
```markdown
[👉](tg://emoji?id=ID_КАСТОМНОГО_ЭМОДЗИ)
```

**Пример отправки сообщения:**
```typescript
await ctx.reply("Привет! Вот анимированный эмодзи: [🔥](tg://emoji?id=5368324170671202286)", {
    parse_mode: "MarkdownV2"
});
```

## 3. Как получить ID любого кастомного эмодзи (`custom_emoji_id`)

### Способ 1: Использование готовых Telegram-ботов
Самый простой способ — отправить нужный эмодзи специальным ботам в Telegram:
* `@getidsbot` — вернет ID эмодзи (удалите квадратные скобки `[]`, если бот пришлет ID в них).
* `@get_emoji_id_bot` — вернет готовый ID и сразу сгенерирует HTML-тег для копирования.

### Способ 2: Написание собственного обработчика на grammY
Добавьте этот обработчик в код вашего бота. Когда вы (или любой Premium-пользователь) отправите боту кастомный эмодзи, бот пришлет в ответ его ID и готовый HTML-код.

Благодаря мощной системе фильтр-запросов grammY, мы можем точечно отлавливать сообщения, содержащие кастомные эмодзи:

```typescript
import { Bot } from "grammy";

const bot = new Bot("ВАШ_ТОКЕН_БОТА");

// Фильтр-запрос grammY ловит любые сообщения, содержащие сущности типа custom_emoji
bot.on("message:entities:custom_emoji", async (ctx) => {
    const entities = ctx.message.entities;
    if (!entities) return;

    for (const entity of entities) {
        if (entity.type === "custom_emoji") {
            const emojiId = entity.custom_emoji_id;
            // Вырезаем оригинальный Unicode-символ (fallback), к которому привязан кастомный эмодзи
            const fallbackEmoji = ctx.message.text 
                ? ctx.message.text.slice(entity.offset, entity.offset + entity.length) 
                : "😊";

            await ctx.reply(
                `<b>Информация об эмодзи:</b>\n` +
                `• ID: <code>${emojiId}</code>\n` +
                `• HTML-код: <code>&lt;tg-emoji emoji-id="${emojiId}"&gt;${fallbackEmoji}&lt;/tg-emoji&gt;</code>`,
                { parse_mode: "HTML" }
            );
        }
    }
});
```

## 4. Полные примеры реализации на grammY

### Пример для Node.js (TypeScript / JavaScript ES6)

Для запуска убедитесь, что установлена библиотека grammY: `npm install grammy`

```typescript
import { Bot } from "grammy";

const bot = new Bot("ВАШ_ТОКЕН_БОТА");

bot.command("start", async (ctx) => {
    const customEmojiHtml = "<tg-emoji emoji-id='5368324170671202286'>🔥</tg-emoji>";
    await ctx.reply(`Добро пожаловать в красочный бот! ${customEmojiHtml}`, {
        parse_mode: "HTML"
    });
});

bot.start();
```

### Пример для Deno (TypeScript)

Deno не требует предварительной установки пакетов, импорт идет напрямую через URL:

```typescript
import { Bot } from "https://deno.land/x/grammy/mod.ts";

const bot = new Bot("ВАШ_ТОКЕН_БОТА");

bot.command("start", async (ctx) => {
    const customEmojiHtml = "<tg-emoji emoji-id='5368324170671202286'>🔥</tg-emoji>";
    await ctx.reply(`Привет из Deno! ${customEmojiHtml}`, {
        parse_mode: "HTML"
    });
});

bot.start();
```

## 5. Цветные кнопки и иконки-эмодзи в grammY

Обновление Telegram Bot API принесло две важнейшие функции для клавиатур:
1. **Цветные кнопки (параметр `style`):** Кнопки теперь можно раскрашивать в 3 цвета:
   * `success` (зеленый) — для целевых и позитивных действий (оплата, подтверждение).
   * `danger` (красный) — для критических и деструктивных действий (удаление, отмена, выход).
   * `primary` (синий) — для стандартной навигации и меню.
2. **Иконки на кнопках (параметр `icon_custom_emoji_id`):** Позволяет установить кастомный эмодзи в качестве иконки. Иконка отображается строго в начале текста кнопки.

### Пример создания клавиатур в grammY

В grammY для построения клавиатур используются классы `InlineKeyboard` (для инлайн-кнопок) и `Keyboard` (для обычных кнопок). Так как grammY использует автоматическую типизацию Telegram Bot API, новые поля `style` и `icon_custom_emoji_id` передаются прямо в объектах кнопок.

```typescript
import { Bot, InlineKeyboard, Keyboard } from "grammy";

const bot = new Bot("ВАШ_ТОКЕН_БОТА");

// 1. Создание цветных Inline-кнопок с кастомными иконками
bot.command("menu", async (ctx) => {
    const inlineKeyboard = new InlineKeyboard()
        .row(
            {
                text: "Оплатить заказ",
                callback_data: "pay",
                style: "success", // Зеленая кнопка
                icon_custom_emoji_id: "5368324170671202286" // ID кастомного эмодзи для иконки
            },
            {
                text: "Удалить",
                callback_data: "delete",
                style: "danger" // Красная кнопка
            }
        )
        .row(
            {
                text: "В главное меню",
                callback_data: "main_menu",
                style: "primary" // Синяя кнопка
            }
        );

    await ctx.reply("Выберите действие:", {
        reply_markup: inlineKeyboard
    });
});

// 2. Создание цветных Reply-кнопок
bot.command("settings", async (ctx) => {
    const replyKeyboard = new Keyboard()
        .row(
            {
                text: "✅ Сохранить изменения",
                style: "success"
            },
            {
                text: "❌ Сбросить",
                style: "danger"
            }
        )
        .resized(); // Автоподбор размера клавиатуры

    await ctx.reply("Настройки профиля:", {
        reply_markup: replyKeyboard
    });
});

bot.start();
```

## 6. Советы по юзабилити и дизайну интерфейсов от Watbot

Для того чтобы бот выглядел профессионально, соблюдайте рекомендации дизайнеров интерфейсов:
* **Не перебарщивайте с цветами:** Два-три цвета в одном меню — это максимум. Если раскрасить все кнопки в разные цвета, интерфейс будет выглядеть хаотично и усложнит восприятие.
* **Используйте один зелёный акцент:** Один зелёный акцент (`success`) на клавиатуре (например, кнопка «Оплатить») работает гораздо сильнее, так как сразу притягивает взгляд к целевому действию.
* **Используйте красный строго по назначению:** Красный цвет (`danger`) подсознательно воспринимается как сигнал тревоги. Используйте его исключительно для деструктивных действий (удалить, очистить, сбросить), чтобы уберечь пользователя от случайного нажатия.
* **Следите за контрастом эмодзи:** Старайтесь не ставить красный эмодзи на красную кнопку (`danger`) или зеленый на зеленую кнопка (`success`) — они сольются и станут неразличимы.
* **Кастомные анимированные эмодзи — точечно:** Анимация отлично удерживает внимание, но если анимированные иконки будут на каждой кнопке, это быстро перегрузит интерфейс и утомит пользователя.

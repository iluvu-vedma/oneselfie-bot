# Шаблоны трансформации текстов для Telegram-бота

Файл содержит Few-Shot примеры (шаблоны "До/После") для обучения модели качественной адаптации текстов под требования мобильного интерфейса Telegram с сохранением синтаксиса Fluent (.ftl).

## Сравнительные кейсы (До / После)

### Кейс 1: Системное уведомление об успешной подписке

**Исходный текст (Нейрослоп, канцелярит, унылый тон):**
```properties
subscription-success = Поздравляем! Ваша транзакция была успешно обработана нашей системой, и теперь вам открыт полноценный доступ ко всем премиальным функциям нашего инновационного бота. Важно отметить, что подписка будет автоматически продлена через 30 дней. Мы искренне рады, что вы выбрали нас для решения ваших повседневных задач!
```

**Целевой вариант (UX-редактирование, живой язык, форматирование Telegram):**
```properties
subscription-success = 🎉 <b>Премиум активирован!</b> Теперь тебе доступны все скрытые функции бота.
    
    💳 Подписка продлится автоматически через 30 дней.
```

## Особенности синтаксиса Fluent (.ftl) в grammY

При редактировании локализации крайне важно сохранять переменные и логику склонений.

### 1. Простая интерполяция переменных
Переменные `{ $name }` должны оставаться нетронутыми.

**TypeScript (код бота):**
```typescript
ctx.t("welcome", { name: "Иван" })
```
**FTL-файл (до редакции):**
```properties
welcome = Рады приветствовать вас в нашем решении, { $name }!
```
**FTL-файл (после редакции — живой ToV):**
```properties
welcome = Привет, { $name }! 👋 Рады видеть тебя здесь.
```

### 2. Склонения и множественное число (Pluralization)
Селекторы множественного числа обрабатываются функцией `NUMBER` и CLDR-правилами локали. Конструкция селектора не должна быть нарушена.

**TypeScript (код бота):**
```typescript
ctx.t("apples", { count: 5 })
```
**FTL-файл (до редакции):**
```properties
apples = У вас имеется { NUMBER($count) ->
    [one] { $count } яблоко
    *[other] { $count } яблок
} в вашей корзине.
```
**FTL-файл (после редакции — лаконично):**
```properties
apples = В твоей корзине: { NUMBER($count) ->
    [one] <b>{ $count }</b> яблоко
    *[other] <b>{ $count }</b> яблок
}.
```

## Допустимые HTML-теги для форматирования в Telegram

Используйте строго ограниченный набор тегов для выделения информации:
- `<b>текст</b>` или `<strong>текст</strong>` — для важных акцентов, заголовков блоков и имен.
- `<i>текст</i>` или `<em>текст</em>` — для примечаний, цитат и подписей.
- `<code>текст</code>` — для системных команд, промокодов, реферальных ссылок, номеров кошельков и транзакций. Такой текст пользователь может скопировать в один клик в мобильном приложении.
- `<pre>текст</pre>` — для сохранения форматирования (таблиц, логов).
- `<a href="https://...">текст ссылки</a>` — для аккуратных гиперссылок (без громоздких URL в теле сообщения).

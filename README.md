# OneSelfie

Нейрофотосессия в Telegram. Один сценарий целиком:
`/start` → пример → 1–4 селфи → пейволл → покупка искр → кадр за 12 ✨ → повтор.

Бот: [@OneSelfie_bot](https://t.me/OneSelfie_bot)

## Чего не хватает для запуска

| Что | Где взять | Без этого |
|---|---|---|
| `KIE_API_KEY` | kie.ai → API keys | генерация не работает |
| `UPSTASH_REDIS_REST_URL` / `_TOKEN` | Upstash free tier или Vercel KV | бот падает на старте |
| `PUBLIC_URL` | адрес деплоя на Vercel | kie некуда стучаться |
| `OWNER_CHAT_ID` | напишите боту, посмотрите логи | нет `/stats` и лога провалов |
| `EXAMPLE_IMAGE_URL` | **сетка ваших реальных результатов** | шаг 2 уходит текстом |
| Шаг 0 из ТЗ | 5 генераций своего лица в плейграунде kie | оффер не проверен |

**Шаг 0 остаётся невыполненным.** Код написан под допущение «непохожесть лечится
промптом». Если 3 из 5 кадров непохожи — крутится `PROMPT_PREFIX` в
`src/config.ts`, а при неудаче переписывается оффер. Технический каркас
(искры, оплата, коллбэки, возвраты) от этого не меняется.

## Устройство

```
src/config.ts    все константы: модель, курс, цены, пакеты, промпт-преамбула
src/scenes.ts    30 зашитых сценариев + сборка промпта
src/kv.ts        Upstash/Vercel KV, ключи, счётчики
src/store.ts     состояние: профиль, баланс, селфи, задачи, платежи
src/kie.ts       заливка селфи, createTask, recordInfo
src/ui.ts        все тексты и клавиатуры
src/flow.ts      экраны сценария и запуск генерации
src/deliver.ts   выдача кадра и возврат искр
src/stats.ts     /stats
src/bot.ts       хендлеры grammY
api/bot.ts           вебхук Telegram
api/kie-callback.ts  приём результата от kie
api/sweep.ts         аварийный добор и таймауты
```

Смена модели, цены кадра или состава пакетов — правка **только** `src/config.ts`.

## Развёртывание

```bash
npm install
cp .env.example .env   # заполнить
npm run check          # экономика и состояние сходятся
```

Деплой на Vercel, затем в переменные окружения проекта кладутся всё то же,
что в `.env`, плюс `PUBLIC_URL` = адрес деплоя. После деплоя:

```bash
npm run set-webhook
```

## Крон

`vercel.json` объявляет `/api/sweep` раз в минуту. **На тарифе Hobby Vercel
запускает крон только раз в сутки** — этого мало: аварийный добор нужен через
90 секунд. Варианты:

- внешний планировщик (cron-job.org, 1 минута, бесплатно) на
  `https://<домен>/api/sweep?secret=<CALLBACK_SECRET>`;
- либо тариф Pro.

Без работающего крона потеря коллбэка означает списанные искры без кадра —
ровно тот кластер жалоб, который нельзя повторять.

## Проверки

```bash
npm run check
```

`scripts/check-economy.ts` — правило 50%, делимость пакетов на 12, состав кнопок.
`scripts/check-state.ts` — двойной тап, двойной коллбэк, единственный возврат,
единственное зачисление платежа, круг по сценариям, `/new` без потери баланса.
`scripts/preview-screens.ts` — печатает все экраны, чтобы вычитать копирайт.
